# Valorant Stats Tracker 🎯

Un tracker web moderno, optimizado para uso personal (~10 jugadores) construido usando HTML5, JavaScript ES6+, Tailwind CSS y automatizado vía **GitHub Actions** y **GitHub Pages**.

## Arquitectura y Seguridad

- **Frontend Estático:** El cliente consume exclusivamente `stats.json`.
- **API Key Protegida:** La clave API de HenrikDev sólo está accesible en el backend efímero de GitHub Actions.
